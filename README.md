# 🔴 Live Shop Clip — ตัดคลิปรีวิวร้านแนว "ไลฟ์สดอลังการ" อัตโนมัติ

ใส่คลิปดิบที่อัดด้วยมือถือ 1 ไฟล์ → ได้คลิปแนวตั้ง 9:16 พร้อมโพสต์ ภายในคำสั่งเดียว

**สิ่งที่โปรแกรมทำให้เองทั้งหมด**

- ✂️ ตัดช่วงเงียบ และตัดช่วงที่พูดผิดออก
- 💬 ถอดเสียงภาษาไทย ทำซับเด้งทีละคำ และไฮไลต์คำสำคัญเป็นสีเหลือง
- 🔴 บรรยากาศไลฟ์สด: ป้าย LIVE กระพริบ, โลโก้ร้าน, หัวใจลอย
- 🎬 โมชั่นตามจังหวะที่พูด: ป้ายชื่อร้าน, หน้าเพจในมือถือ, อัลบั้มรูปหน้าร้าน, การ์ดสินค้า, แผนที่ร้าน, ป้ายที่จอดรถ, เวลาเปิด-ปิด, ช่องค้นหาเพจ
- 💥 ตัวหนังสือวิ่งไปอยู่ "หลังตัวคน", จอสั่น, แฟลช, ซูม, ปิดท้ายด้วยระเบิดเข้าหน้าร้าน
- 🔊 ใส่เพลงประกอบ + เสียงเอฟเฟกต์ และปรับระดับเสียงให้ดังได้มาตรฐานโซเชียล (-14 LUFS)

ในโปรเจกต์ใส่ตัวอย่างร้าน **มิกิ from japan** ไว้ให้ครบแล้ว เปิด `project.json` ดูเป็นแบบได้เลย

## ขั้นที่ 2 — ติดตั้งโปรแกรม (ครั้งเดียว)

ตัวติดตั้งจะลงให้ครบทุกอย่างอัตโนมัติ: **ffmpeg** (ตัดต่อวิดีโอ), **Node.js** (ระบบโมชั่น), **Python** + **pythainlp** (ตัดคำภาษาไทย), **HyperFrames** (เรนเดอร์วิดีโอ) และเบราว์เซอร์สำหรับเรนเดอร์

### 2.1 ดาวน์โหลดโปรเจกต์

**วิธีง่าย:** กดปุ่มสีเขียว **Code** บนหน้า GitHub → **Download ZIP** → แตกไฟล์ไว้ที่ไหนก็ได้ เช่น ใน `เอกสาร` (Documents)

**ถ้ามี git:**
```bash
git clone https://github.com/gobank01/live-shop-clip.git
```

### 2.2 รันตัวติดตั้ง

#### 🍎 Mac

1. เปิดแอป **Terminal** (กด `⌘ + Space` แล้วพิมพ์ `Terminal`)
2. พิมพ์ `cd ` (มีเว้นวรรคต่อท้าย) แล้ว **ลากโฟลเดอร์ live-shop-clip** มาวางในหน้าต่าง Terminal จากนั้นกด Enter
3. รันตัวติดตั้ง:

```bash
bash setup.sh
```

- ถ้ายังไม่มี Homebrew ระบบจะถาม **รหัสผ่านเครื่อง Mac** ให้พิมพ์รหัสแล้วกด Enter (ตัวหนังสือจะไม่ขึ้นตอนพิมพ์ เป็นเรื่องปกติ)
- ใช้เวลาประมาณ 5–15 นาที ขึ้นกับความเร็วเน็ต
- ตอนท้ายจะถามคีย์ ElevenLabs ให้วางคีย์ได้เลย (ดูวิธีเอาคีย์ในขั้นที่ 3)

#### 🪟 Windows

1. เปิดโฟลเดอร์ `live-shop-clip`
2. **ดับเบิลคลิก `1-ติดตั้ง.bat`**
3. ถ้ามีหน้าต่างขออนุญาต (สีฟ้า/เหลือง) ให้กด **Yes** ทุกครั้ง
4. ตอนท้ายจะถามคีย์ ElevenLabs ให้วางคีย์แล้วกด Enter

> ถ้าขึ้นว่า **ไม่พบ winget** ให้เปิด Microsoft Store แล้วติดตั้งแอป **App Installer** ก่อน จากนั้นดับเบิลคลิก `1-ติดตั้ง.bat` ใหม่
> ถ้าติดตั้ง Python/Node เสร็จแต่ยังขึ้นว่าหาไม่เจอ ให้ **ปิดหน้าต่างแล้วดับเบิลคลิก `1-ติดตั้ง.bat` อีกครั้ง**

### 2.3 ตรวจว่าติดตั้งครบ

ตัวติดตั้งจะตรวจให้ตอนจบ ถ้าครบทุกข้อจะขึ้นแบบนี้:

```
✅ ffmpeg
✅ ffprobe
✅ node
✅ pythainlp
✅ hyperframes
✅ ELEVENLABS_API_KEY ใน .env

พร้อมใช้งาน 🎉
```

ตรวจซ้ำเองได้ทุกเมื่อ: Mac พิมพ์ `python3 make.py check` / Windows พิมพ์ `2-ตัดคลิป.bat check`

## ขั้นที่ 3 — ใส่คีย์ ElevenLabs

ElevenLabs ใช้ถอดเสียงพูดภาษาไทยเป็นซับ (คลิป 1 นาทีใช้เครดิตน้อยมาก)

1. สมัคร/ล็อกอินที่ https://elevenlabs.io
2. ไปที่ https://elevenlabs.io/app/settings/api-keys → กด **Create API Key** → เปิดสิทธิ์ **Speech to Text** → กดคัดลอกคีย์
3. ถ้าตอนติดตั้งข้ามไปแล้ว: เปิดไฟล์ `.env` ในโฟลเดอร์โปรเจกต์ด้วยโปรแกรม Notepad / TextEdit แล้ววางคีย์ต่อท้ายเครื่องหมาย `=`

```
ELEVENLABS_API_KEY=sk_xxxxxxxxxxxxxxxxxxxx
```

> 🔒 ห้ามส่งไฟล์ `.env` หรือคีย์ให้คนอื่น — ไฟล์นี้ถูกตั้งไว้ไม่ให้ขึ้น GitHub อยู่แล้ว
> 💡 บน Mac ไฟล์ที่ขึ้นต้นด้วยจุดจะถูกซ่อน กด `⌘ + Shift + .` ใน Finder เพื่อให้เห็น

## ขั้นที่ 4 — วางไฟล์ของร้าน

วางไฟล์ในโฟลเดอร์ `input/` ตามนี้

```
input/
├── raw.mp4          ← คลิปดิบ แนวตั้ง 9:16 (อัดจากมือถือได้เลย)
├── logo.jpg         ← โลโก้ร้าน รูปสี่เหลี่ยมจัตุรัส
└── photos/
    ├── 1.jpg        ← รูปหน้าร้าน / ในร้าน / สินค้า (แนวตั้งดีที่สุด)
    ├── 2.jpg
    ├── 3.jpg
    ├── 4.jpg
    └── 5.jpg
```

**เคล็ดลับการอัดคลิปให้ออกมาสวย**

- ถือมือถือ **แนวตั้ง** ให้หน้าคนพูดอยู่ **ช่วงกลางจอ** และเหลือที่ว่างเหนือหัวนิดหน่อย (ตัวหนังสือ "หลังตัวคน" จะอยู่ตรงนั้น)
- พูดเป็นประโยคชัดๆ เว้นจังหวะได้ โปรแกรมจะตัดช่วงเงียบออกให้เอง
- ถ้าพูดผิด พูดใหม่ต่อได้เลย แล้วไปใส่ช่วงที่ผิดไว้ใน `cut.remove` (ขั้นที่ 5)
- ความยาวที่เหมาะ: 40–90 วินาที

รูปสินค้าในฉากการ์ดสินค้าใช้ไฟล์ไหนก็ได้ (`.jpg` / `.png`) ใส่ path ไว้ใน `project.json` — ในตัวอย่างใช้รูปที่ `examples/miki-from-japan/products/`

## ขั้นที่ 5 — แก้ข้อมูลร้านใน project.json

เปิด `project.json` ด้วยโปรแกรมแก้ข้อความ (แนะนำ [VS Code](https://code.visualstudio.com/) ฟรี) แล้วแก้ 3 ส่วนนี้

### 5.1 `shop` — ข้อมูลร้าน

| ช่อง | ใส่อะไร | ตัวอย่าง |
|---|---|---|
| `name` | ชื่อร้าน (ขึ้นป้าย LIVE, แผนที่, หน้าปิด) | `"มิกิ from japan"` |
| `tagline` | สโลแกนสั้น | `"สินค้านำเข้าจากญี่ปุ่น มือ 1"` |
| `category` | ประเภทร้านใต้ชื่อในหน้าเพจ | `"ร้านขายเสื้อผ้า · นนทบุรี"` |
| `followers` | ยอดผู้ติดตามเพจ (ตัวเลขจริง) | `"327K ผู้ติดตาม"` |
| `live` | เวลาไลฟ์ | `"🔴 LIVE สด ทุก ศ. ส. อา."` |
| `location` | ที่ตั้ง | `"📍 บางใหญ่ นนทบุรี · สาขาเดียว"` |
| `search` | คำที่พิมพ์ในช่องค้นหาตอนท้าย | `"มิกิ from japan"` |
| `socials` | ปุ่มโซเชียล (สูงสุด 4 ปุ่ม) | `{"name": "LINE", "color": "#06c755"}` |
| `info` | 3 บรรทัดในหน้าปิดท้าย | ที่อยู่ / เวลาเปิด / เวลาไลฟ์ |
| `follow` | ช่องทางติดตามในกล่องแดงหน้าปิด | `"IG @mikijapan.shop"` |

### 5.2 `scenes` — ฉากโมชั่น (หัวใจของคลิป)

**ทุกฉากจะโผล่ "ตอนที่คนในคลิปพูดคำนั้น"** — ใส่คำที่พูดใน `when` ไม่ต้องจับเวลาเอง

```json
{"type": "badge", "when": "ลานจอดรถ", "icon": "P", "text": "ลานจอดรถกว้างขวาง"}
```
แปลว่า: พอคนในคลิปพูดว่า "ลานจอดรถ" ให้ขึ้นป้าย P พร้อมข้อความ "ลานจอดรถกว้างขวาง"

- `when` = คำที่พูด ตอนเริ่มฉาก (ต้องตรงกับที่โปรแกรมถอดเสียงได้ — ดูได้ใน `work/transcript.txt` หลังรันครั้งแรก)
- `until` = คำที่พูด ตอนจบฉาก (ไม่ใส่ก็ได้ จะใช้ความยาวมาตรฐาน)
- `at` = ใส่เป็นวินาทีแทนคำก็ได้ เช่น `"at": 12.5`
- ฉากจะถูกค้นหา **ตามลำดับ** — คำซ้ำ (เช่นชื่อร้านที่พูดหลายรอบ) จะจับครั้งถัดไปหลังฉากก่อนหน้าเอง
- ไม่อยากได้ฉากไหน **ลบออกทั้งบรรทัด** ได้เลย

**ฉากทั้งหมดที่มี**

| `type` | หน้าตา | ช่องที่ใส่ได้ |
|---|---|---|
| `hook` | ตัวหนังสือใหญ่ 2 บรรทัดตอนเปิดคลิป | `lines`, `until` |
| `stamp` | การ์ดโลโก้ + ชื่อร้านกระแทกเข้ามา | `when`, `title` (2 บรรทัด), `sub` |
| `chips` | ป้ายจุดเด่นเลื่อนเข้าจากซ้าย + ธงญี่ปุ่น | `items` (`when` + `text`), `flag` (true/false), `until` |
| `page` | มือถือโชว์หน้าเพจร้าน | `when`, `until`, `photos` (4 รูป), `label` |
| `gallery` | กล้องย่อมุมขวา + รูปหน้าร้าน 3 ใบ + ป้ายหมวด | `when`, `until`, `eyebrow`, `title`, `photos`, `tags` |
| `zoom` | ซูมเข้าหน้า + แถบดำบนล่าง + ป้ายข้อความ | `when`, `until`, `text` |
| `behind` | ตัวหนังสือยักษ์อยู่หลังตัวคน | `when`, `text` (สั้นๆ 3–5 ตัว), `dur` |
| `products` | การ์ดสินค้า 4 ใบเด้งตามคำที่พูด + หิมะ | `when`, `until`, `eyebrow`, `title`, `note`, `items` (`when`, `img`, `label`, `tag`), `trip`, `snow` |
| `map` | แผนที่ + หมุดร้าน + ถนน + รถไฟฟ้า | `when`, `until`, `eyebrow`, `title`, `road`, `train`, `parking` |
| `badge` | ไอคอนใหญ่ + ข้อความ (ที่จอดรถ, ส่งฟรี ฯลฯ) | `when`, `icon`, `color`, `text`, `dur` |
| `hours` | การ์ดเวลาเปิด-ปิด | `when`, `day`, `time` |
| `cta` | ช่องค้นหาพิมพ์ชื่อร้าน + ปุ่มโซเชียล | `when` |

> ⚠️ ถ้ารูปสินค้าไม่ใช่สินค้าจริงของร้าน ให้ใส่ `note` เช่น `"ตัวอย่างสินค้า · สินค้าจริงดูได้ที่ร้าน"` เสมอ

### 5.3 `cut` — ตัดช่วงที่พูดผิด

```json
"cut": {
  "remove": ["จะมาจะจะไปช้อปปิ้งนะคะเอ้ยจะไปเที่ยวต่างประเทศนะ"]
}
```
ใส่ประโยคที่พูดผิดตามที่ถอดเสียงได้ (ดูจาก `work/transcript.txt`) หรือใส่เป็นช่วงวินาทีของคลิปดิบ เช่น `[30.5, 34.4]`

### 5.4 อื่นๆ

- `keywords` — คำที่อยากให้ซับเป็น **สีเหลือง**
- `output_name` — ชื่อไฟล์คลิปที่ได้
- `bgm` / `bgm_volume` — เปลี่ยนเพลงประกอบ (ใส่ไฟล์ .mp3 ของคุณเอง) และความดัง (0.05–0.15)
- `style.caption_bottom` — ระยะซับจากขอบล่าง (พิกเซล) ถ้าซับบังหน้าให้ลดเลข
- `style.face` — ตำแหน่งหน้าคนในเฟรม `[x, y]` ใช้ตอนซูม

## ขั้นที่ 7 — แก้ซับ / แก้ฉาก แล้วเรนเดอร์ใหม่

1. **แก้คำผิดในซับ:** เปิด `captions.json` แต่ละบรรทัดคือ `[เริ่ม, จบ, "ข้อความ"]` แก้เฉพาะข้อความได้เลย
2. **แก้ฉาก / ข้อมูลร้าน:** แก้ `project.json`
3. ดูตัวอย่างก่อนเรนเดอร์จริง (ไม่บังคับ): `python3 make.py preview` จะเปิดหน้าดูคลิปในเบราว์เซอร์
4. เรนเดอร์ใหม่ **โดยไม่ถอดเสียงซ้ำ** (ไม่เสียเครดิต):

```bash
python3 make.py render
```
(Windows: เปิด Command Prompt ในโฟลเดอร์ แล้วพิมพ์ `2-ตัดคลิป.bat render`)

> ⚠️ `python3 make.py` (ไม่มีคำต่อท้าย) จะ **สร้างซับใหม่ทับ** captions.json — ใช้ตอนเปลี่ยนคลิปใหม่เท่านั้น
> เปลี่ยนคลิปใหม่: แค่วาง `input/raw.mp4` ไฟล์ใหม่ทับ แล้วรัน `python3 make.py`

### สรุปคำสั่งทั้งหมด

| คำสั่ง | ทำอะไร |
|---|---|
| `python3 make.py` | ทำครบทุกขั้น (คลิปใหม่) |
| `python3 make.py render` | เรนเดอร์ใหม่หลังแก้ซับ/ฉาก |
| `python3 make.py preview` | เปิดดูตัวอย่างในเบราว์เซอร์ |
| `python3 make.py build` | ประกอบอย่างเดียว ไม่เรนเดอร์ (เช็กว่าเจอทุกฉากไหม) |
| `python3 make.py check` | ตรวจว่าติดตั้งครบ |
